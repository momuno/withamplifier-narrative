Sound familiar?

If you've built with AI frameworks, you've hit these walls.

You picked a framework. It got you to a demo fast. Then you needed something it wouldn't let you do.

01

The provider isn't yours.

When the best model changes quarterly, you're constrained by what the framework supports. Your agent logic, tool interfaces, error handling — all tied to one vendor's SDK. Not because the problem changed, but because the framework assumed your provider was permanent.

With Amplifier

Provider is a module. Five methods. Implement the Protocol, and the kernel treats yours the same as any official one. Swap by changing one YAML line. Run multiple simultaneously.

02

The agent loop isn't yours.

Your framework gives you an agent loop that works — until you need the agent to pause for human approval, consult a second model for verification, or handle long conversations differently than silent truncation. You can add a callback. You can't change the loop.

With Amplifier

The orchestrator is a module. Replace the entire execution loop. Same tools, same hooks, same memory — completely different behavior.

03

Interjection isn't yours.

Your framework fires events. You can log them, maybe block them. But you can't modify a message in flight or inject context that changes how the agent reasons. Observation without participation.

With Amplifier

Hooks are a control plane with five actions: continue, deny, modify, inject_context, ask_user. inject_context means hooks participate in the agent's reasoning, not just the logging.

Use it

Inject context into conversations. A hook that teaches — not by blocking, but by injecting context so the agent self-corrects.

hooks/commit_convention.py
async def commit_convention_hook(event, data):
    if event != "tool:pre" or data.get("tool_name") != "bash":
        return HookResult(action="continue")

    command = data.get("tool_input", {}).get("command", "")
    if not command.startswith("git commit"):
        return HookResult(action="continue")

    if not re.match(r'git commit -m ["\'\\]?(feat|fix|docs)', command):
        return HookResult(
            action="inject_context",
            context_injection="Commit messages must follow "
                "conventional format: feat|fix|docs|refactor: description",
        )

    return HookResult(action="continue")

Make it yours

Bundles compose capabilities. Recipes orchestrate multi-step workflows with approval gates.

bundle.yaml
bundle:
  name: my-dev-setup
  version: 0.1.0

includes:
  - foundation
  - recipes
  - python-dev

providers:
  - module: provider-anthropic
    config:
      model: claude-sonnet-4-5

hooks:
  - module: hooks-approval
  - module: hooks-redaction
recipes/pr-review.yaml
name: pr-review
stages:
  review:
    steps:
      - agent: python-dev
        prompt: "Review {repo_path} for quality"
      - agent: security-guardian
        prompt: "Audit for vulnerabilities"

  approve:
    needs_approval: true

  report:
    steps:
      - agent: technical-writer
        prompt: "Synthesize findings into a report"
